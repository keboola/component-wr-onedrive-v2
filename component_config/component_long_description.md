This writer uploads Keboola input mappings to Microsoft OneDrive and SharePoint document libraries via Microsoft Graph. Each configuration row targets one destination in one of two modes: File (upload mapped files as-is and write mapped tables as CSV files) or Worksheet (write a table into an Excel worksheet, creating the workbook and worksheet when needed, with overwrite or append semantics). It connects to Private OneDrive, OneDrive for Business, or SharePoint accounts — including non-default document libraries on SharePoint sites — and lets you choose how to handle naming conflicts (fail, replace, or rename) for File mode targets. This component supersedes the OneDrive Excel Sheets writer, adding file and CSV output alongside full feature parity for Excel worksheet writes.
