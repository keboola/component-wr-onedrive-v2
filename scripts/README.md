# Scripts

`authorize_oauth.py` — interactive, one-time helper that runs the Microsoft identity platform
delegated-OAuth authorization-code flow against a local redirect URI and writes the resulting
`refresh_token` (plus the app credentials you enter) into a gitignored `secrets.json` at the repo
root. Run this once before recording VCR cassettes, whenever the test tenant's refresh token has
expired or been revoked, or when switching to a different test app registration. Never commits
anything — everything lands only in `secrets.json`.

`record_vcr_cassettes.py` — records every scenario declared in `tests/setup/configs.json` against
the live Microsoft 365 test tenant, reading credentials from `secrets.json`, sanitizing secrets
and PII out of every recorded interaction, and writing the result to `tests/functional/<name>/`.
This is the only thing that ever produces or updates the cassettes `tests/e2e/test_functional_vcr.py`
replays offline. See `tests/functional/README.md` for the full record/re-record procedure and
`secrets.json` shape.

`generate_empty_workbook_fixture.py` — one-off generator for `src/client/fixtures/empty.xlsx`, the
minimal valid workbook the component embeds and loads at runtime (via `importlib.resources`) when
it needs to create a brand-new workbook from scratch. Only re-run this if that fixture needs to
change; the generated bytes are committed so the runtime image never needs `openpyxl` installed.

`build_n_test.sh` — the Docker `test` stage's entrypoint: runs `ruff check` (lint failures block
the build) then `pytest tests/ --tb=short -q`. Mirrors the `cookiecutter-python-component`
template this repo tracks — keep changes to it minimal and template-compatible.

`developer_portal/` — CI scripts (owned by the `cookiecutter-python-component` template) that push
`component_config/*` to the Keboola Developer Portal on release. Template-owned: do not hand-edit;
changes should flow from the template instead.
